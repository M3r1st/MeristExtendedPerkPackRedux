# [WOTC] Extended Perk Pack Redux

Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3647614305

## What is this?

This is a redux version of *[WOTC] Extended Perk Pack* by **Favid**. Its goal is to improve compatibility with other mods as well as fix some of the issues the original mod contains.

**List of abilities (WIP)**

## What's different?

* Removed XModBase.
* A lot of bugfixes.
* A lot of values and properties were exposed to config.
* Iridar's ConfigEngine is now used for non-list values to give other mods more control over config.

## Configuration

* Almost all configurable values can be found in `XComGameData_SoldierSkills.ini`.

## Requirements

* Community Highlander is *required*.
* Some abilities require additional mods to work. See **List of abilities (WIP)** for details.
